# Ace — Privacy Policy

Last updated: 2 November 2026

Ace is a private creative assistant built and used by Nungo Tshidzumba
(Pretoria, South Africa). It is not offered to the public.

## What Ace accesses from Pinterest
With my permission, Ace reads my own Pinterest boards and saved Pins
(read-only). It does not post, edit, or delete anything on Pinterest, and it
never accesses other users' accounts or data.

## How the data is used
Board and Pin information is used only to understand my personal style and
to suggest outfits and creative ideas inside Ace. It is not used for
advertising, and it is never sold or shared with third parties.

## Where it is stored
Data is stored in my own private cloud accounts (Microsoft Azure and MongoDB
Atlas). Access to Ace is protected by a private passphrase. Text may be
processed by AI model providers (Microsoft Azure OpenAI, NVIDIA) to generate
responses.

## Retention and deletion
I can disconnect Pinterest and delete stored Pinterest data from Ace at any
time. Access can also be revoked from Pinterest's own settings under
connected apps.
